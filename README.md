# Venture Civil and Consultancy Services site

Static multi-page website. No package installation or framework build is required.

## Cloudflare Pages

For Git integration, use:

- Build command: `./build.sh`
- Build output directory: `dist`

For Direct Upload, run `./build.sh` and upload the generated `dist` folder.

The build copies only the public website files, so the local original-page backup and macOS metadata are not included.
